# Code of Conduct

## Our standard

Be respectful, constructive, and technically focused when participating in this project. Harassment, personal attacks, discriminatory language, threats, doxxing, and deliberate disruption are not acceptable.

Disagreement about protocol behavior, client support, evidence quality, or project direction is welcome when it stays focused on the work and the available evidence.

## Scope

This code applies to repository Issues, pull requests, reviews, and other project spaces controlled by the maintainers.

Maintainers may edit, hide, lock, or remove content, or restrict participation, when necessary to keep project spaces safe and productive. Platform-wide abuse may also be reported through GitHub's own reporting and blocking controls.

## Reporting boundary

Do not use a public Issue to disclose a security vulnerability; follow [SECURITY.md](SECURITY.md) instead.

The repository does not currently promise a separate private conduct-reporting mailbox. Do not send conduct complaints through the vulnerability-reporting channel unless the report is itself about a security vulnerability. Where a private conduct report is necessary, use the private reporting mechanisms provided by GitHub for the relevant account or content.
