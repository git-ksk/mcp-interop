# Support

[English](SUPPORT.md) | [日本語](SUPPORT.ja.md)

This is a community-maintained open-source project. It does not provide a commercial SLA or private support service.

## Where to ask

- **Bug or interoperability problem:** open a GitHub Issue using the closest matching bug or real-client interoperability template.
- **Feature or enhancement request:** open a GitHub Issue using the feature-request template.
- **General usage question:** open a GitHub Issue using the question template.
- **Suspected security vulnerability:** do **not** open a public Issue. Use GitHub Private Vulnerability Reporting as described in [SECURITY.md](SECURITY.md).

GitHub Discussions are not enabled for this repository, so support is not routed there.

Before posting diagnostics, remove credentials and sensitive deployment data. Do not include access/refresh tokens, OAuth authorization codes or state, raw authorization URLs, cookies, client secrets, private keys, credential files, or sensitive endpoint query values.
