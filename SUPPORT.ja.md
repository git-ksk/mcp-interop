# サポート

[English](SUPPORT.md) | [日本語](SUPPORT.ja.md)

このprojectはcommunity-maintained open-source projectです。commercial SLAやprivate support serviceは提供していません。

## 問い合わせ先

- **Bug / interoperability problem:** GitHub Issueでbugまたはreal-client interoperabilityの適切なtemplateを使用してください。
- **Feature / enhancement request:** GitHub Issueのfeature-request templateを使用してください。
- **General usage question:** GitHub Issueのquestion templateを使用してください。
- **Security vulnerabilityの疑い:** public Issueを作成しないでください。[SECURITY.ja.md](SECURITY.ja.md)に従いGitHub Private Vulnerability Reportingを使用してください。security reporting policyのcanonical版は[SECURITY.md](SECURITY.md)です。

このrepositoryではGitHub Discussionsを有効化していないため、support先として案内しません。

diagnosticを投稿する前にcredentialやsensitive deployment dataを除去してください。access/refresh token、OAuth authorization code/state、raw authorization URL、cookie、client secret、private key、credential file、sensitive endpoint query valueを含めないでください。
